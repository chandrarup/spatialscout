# The SAM structure condition is exploratory

Amends ADR-0005. Box-prompted SAM 3.1 outlines on a nucleus rendering have not been checked against expert annotation, and tuft-gene enrichment is only a consistency check: a smaller mask can raise enrichment while omitting real tissue. So the structure-constrained condition is reported beside the primary conditions in tables, the split slider and figures, badged "SAM 3.1 proposal (exploratory)", and it never enters an evidence label. Every outline is compared with its seed box and a convex-hull baseline on area, coverage, retention and PECAM1/PDGFRB consistency; empty, fragmented or rejected proposals are recorded rather than forced; outlines carry a mask version and run id. An anatomical accuracy claim needs an independently checked subset, which this release does not have.
