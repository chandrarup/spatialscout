## What the demonstration should establish

A scientist can inspect real tissue, run a correctly scoped calculation, delegate a recorded investigation, examine alternative interpretations, explore measured depth, challenge a numerical claim and take away reproducible evidence. The useful result is a research lead with its limitations. The baseline and label-control limitations are part of that result.

The actual portal asks for a 3-minute demo video. Aim for 2:55–3:00 including the ending. The voiceover below is about 396 words; rehearse the timings rather than speeding up the narration. Trim a visual detour if necessary, keeping the interpretation caveats.

## Click-path details and branches

### B-cell result and the two baselines

The chapter may initially focus the other branch or show the run rather than Findings. Navigate to the actual B-cell UMOD finding; under **See the findings**, expand **Part 2** and show its computed figure. Use **See it on the tissue** or the run evidence selection to return to the same region before opening depth mode. Rehearse this navigation. The baseline plot is worth more than a decorative animation.

The old “refuted” label means the frozen rule did not match the prediction that the signal drops. It is not a direct test of spillover. Keep the baseline caveat in the voiceover even if the stored prediction label remains visible. The supplied evaluation also says the two label rules yield the same B-cell population, so avoid calling that a successful independent robustness check.

If the implementation adds a genuinely different B-cell labelling control or baseline sensitivity analysis before recording, show its actual new artifact and adjust the script. Preserve old recording identity; new evidence is not retroactively an action of the old run. Do not manufacture a confidence interval or p-value for correlated sections with unknown donor mapping.

### If the ROI is insufficient

Leave the state visible. Say: **“This region has too few cells for the requested conclusion. The tool tells me why. I can select a larger region or keep the result descriptive.”** If time permits enlarge it and recompute; otherwise continue. This demonstrates sensible abstention rather than a failure to hide.

### If 3D takes too long

Use a separate short capture of the same verified evidence region and show a cut in the video. Keep the section/source and descriptive-depth labels. Say measured molecule depths, not 3D reconstruction or a newly proven mechanism. Protein channel stacks do not imply z-stacks.

### If the sample audit exceeds the last ten seconds

Show the compatible files/sample entry point and end; do not wait or pretend it finished. Alternatively show the actual completed sample calculation in a clearly edited short clip. Prefer completing the report/export beat over visiting Connections in the final seconds.

### If you demonstrate offline verification yourself

Replace the attributed evaluator sentence with: **“Here is the verification notebook from the package we just downloaded. Its checks pass. ## What to say if asked

- **Is this live?** “The main investigation and lab are genuine recorded runs, played back with their original provenance. Box audits, the depth profile and the compatible sample audit compute fresh without a new model call.” If the final server offers live mode, explain its actual gate separately.
- **Did you fine-tune SAM?** “No. We use box-prompted SAM 3.1 for exploratory outlines. Those outlines do not determine the primary evidence labels.” The featured investigation does not contain a SAM call; demonstrate outlines as a separate capability if needed.
- **Did you prove B cells make UMOD?** “No. The signal remains under tested restrictions; baseline choice and uncertain cell labels limit its interpretation. An orthogonal experiment is needed.”
- **Did a kidney researcher validate it?** “This evaluation exercised source code, endpoints, figures and an exported package. It did not test browser usability or establish biological validity.” Attribute any later human review separately with consent.
- **How much time does it save?** “The recorded investigation took 179 seconds at approximately $0.29 in model calls; the lab has separate time/cost. We have not measured a manual-workflow comparison.”
- **Does it outperform other models?** “We have not run a controlled comparison. We demonstrate an integrated domain workflow using complementary Meta models.”

## Claims to keep out of this recording

- That the B-cell population check varies labels when it leaves membership unchanged.
- That 12.3% exceeds both random-loss baselines; it exceeds 9.5%, but is below 13.7%.
- That persistence rules out contamination, confirms gene origin, or proves vertical overlap.
- That the code/endpoint evaluation tested animation, loading feel, usability or clinical accuracy.
- That the original run made six live injected-error tests; its main trace has one wrong copy, with separate stored challenge variants.
- That zero co-mentions in the fetched titles/abstracts proves novelty.
- That healthy-versus-CKD protein observations from separate imaging runs establish a disease effect or matched replication.
- That the whole application is hospital-private, public BYOK is ready, LN was analysed, or weeks were saved without corresponding implementation/evidence.
